# Происхождение и лицензии

Проверено 2026-10-09. Это сведения о составе проекта; единая лицензия на весь комплект не заявляется.

| Компонент | Источник | Условия / статус |
| --- | --- | --- |
| Исходная обвязка KVAS | [qzeleza/kvas](https://github.com/qzeleza/kvas) | Apache-2.0, исходный [LICENCE.md](licenses/KVAS-LICENCE.md) сохранён |
| Исходный Telegram-бот | [dnstkrv/telegram4kvas](https://github.com/dnstkrv/telegram4kvas) | В просмотренном дереве main не найден файл лицензии; разрешение на перераспространение требует уточнения |
| Встроенная библиотека telebot | [pyTelegramBotAPI](https://github.com/eternnoir/pyTelegramBotAPI) | [GPL-2.0](licenses/pyTelegramBotAPI-GPL-2.0.txt), не MIT; встроенные уведомления отдельных файлов сохраняются |

| Go runtime | [Go](https://go.dev/) | [BSD-style](vendor/xray/GO-LICENSE) |

Pivas меняет поведение исходной обвязки и бота: группы, слоты, DNS, исключения устройств, обновления и интерфейсы. Изменения описаны в [docs/CHANGELOG.md](docs/CHANGELOG.md). Названия исходных проектов оставлены здесь для атрибуции; пользовательский интерфейс называется Pivas.

Xray для AArch64 взят из официального релиза. MIPSel собран из неизменённых исходников v26.3.27 с другим Go toolchain; параметры и URL исходников записаны в манифесте. Поддержка этого бинарника не означает, что upstream поддерживает конкретный Keenetic.

## Вопрос до публичного выпуска

Старый локальный LICENSE ошибочно ссылался на переименованные upstream-репозитории и называл pyTelegramBotAPI лицензией MIT. Эти сведения исправлены. Отсутствие LICENSE в репозитории бота не означает разрешения перелицензировать его код.

Перед публикацией полного комплекта нужно получить/найти разрешение автора исходного бота либо заменить соответствующий код. Подготовка файлов, локальные проверки и черновик релиза выполнены независимо от этого вопроса. GitHub-workflow не публикует релизы автоматически. Другие компоненты также сохраняют свои лицензии; пакеты зависимостей Entware загружаются отдельно и не включены в исходный архив.
