| Проверка | Результат |
| --- | --- |
| Модульные тесты Python 3.12 | 261 тест, успешно |
| Полная сборка из публичной копии | 17 IPK/установщиков и manifest.json |
| Проверка пакетов | Совпадение с исходниками, оба полных комплекта, шесть вложенных установщиков, SHA-256 |
| Веб | Пять наборов Playwright: e2e, style, slot names, Hysteria, XHTTP — успешно |
| Разрешения экрана | Проверки вёрстки от 320 до 3408 px |
| YAML GitHub | Файлы workflow и issue forms разобраны YAML-парсером |
| Публичные исходники | Проверены Python-синтаксис, относительные Markdown-ссылки, подозрительные имена файлов и типовые секреты |
| Содержимое IPK | 147 уникальных текстовых payload-файлов проверены на типовые токены, личные пути и приватные конфиги |
| Версии | build.py, manifest.json и тег из repository.json согласованы |

Веб проверялся на локальном демо с искусственными адресами; скриншоты получены из него. Это не проверка действующих серверов подключения. Поиск шаблонов секретов не гарантирует обнаружение любых чувствительных данных; перед публикацией нужен просмотр состава коммита.

Использованы уже проверенные бинарники vendor с SHA-256 из манифестов. В рамках подготовки не выполнялась новая компиляция Go-зависимостей и не проверялся чистый запуск GitHub Actions на Linux. Workflow подготовлены, но их запуск на GitHub станет отдельной проверкой после создания репозитория.

Ни репозиторий, ни релиз из этой подготовки не опубликованы. Отдельный незакрытый вопрос — условия перераспространения исходного Telegram-бота, см. [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md).
