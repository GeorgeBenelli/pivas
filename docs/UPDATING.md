# Обновление

Перед обновлением сохраните резервную копию настроек через веб. Скачайте `pivas-full_*.ipk` для своей архитектуры Entware из релиза. В нём сразу Pivas, веб, бот, Xray и QUIC-помощник.

## Через Telegram

Откройте «Сервис → Обновить пакет» и отправьте IPK как документ. Лимит — 20 МБ. Обновление доступно администраторам бота.

Если бот пишет, что `pivas-full` не разрешён, обновите через SSH: старый бот ещё не поддерживает полный пакет.

## Через SSH

Передайте IPK в `/opt/tmp/` и подставьте его имя в команду:

```sh
opkg update
opkg install /opt/tmp/ИМЯ_ПАКЕТА.ipk
```

Если Pivas раньше устанавливался отдельными пакетами, сначала нужна миграция на `pivas-full`. Не обходите конфликты файлов с помощью `--force-overwrite`.

## После обновления

```sh
pivas repair-dns
pivas status
```

После установки через SSH Pivas остаётся на паузе. Запустите его командой `pivas start`. Обновление через бот пытается вернуть прежнее состояние — проверьте его через `pivas status`.

Выполните `pivas vless ping`, затем откройте сайт из каждого слота с клиентского устройства. Проверьте также обычный сайт и устройство с исключением. После обновления Xray должен работать новый процесс; перезагрузка роутера позволяет заодно проверить автозапуск.

Настройки сохраняются при обновлении.
