# Безопасность

Веб работает по HTTP в локальной сети. Не открывайте порт 8888 в интернет. Для удалённого управления подключайтесь к домашней сети через защищённое соединение.

Pivas и бот работают с правами root. Добавляйте в список администраторов бота только тех, кому доверяете управление роутером. Секреты, переданные в командах SSH, могут остаться в истории терминала.

Правила маршрутизации рассчитаны на IPv4. IPv6 и собственный DoH приложений могут обходить их. Для частных TLS-сертификатов можно использовать SHA-256 pin: если отпечаток получен автоматически, первое соединение должно быть доверенным. [Подробнее о DNS и сертификатах](docs/ARCHITECTURE.md).

## Сообщить об уязвимости

Используйте Security → Report a vulnerability, если эта кнопка доступна. Если её нет, откройте issue с просьбой о приватном канале связи, без деталей уязвимости.

Не прикладывайте к публичным задачам пароли, токены, рабочие ссылки, конфиги и резервные копии. Если секрет уже попал в GitHub, замените или отзовите его: удаление файла не убирает его из истории.
