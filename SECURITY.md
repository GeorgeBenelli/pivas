# Безопасность

Поддерживаемая для проверки версия — текущий 1.2.0-beta.1. Исправления старых вариантов могут потребовать обновления всего комплекта.

Pivas и Telegram-бот выполняют привилегированные действия на роутере. Доступ к боту выдаётся только указанным администраторам. Командный интерфейс бота не является песочницей: фильтр отдельных команд не заменяет контроль доступа.

Веб доступен по HTTP в LAN. Используйте доверенную сеть и не открывайте порт 8888 в WAN. Для удалённого доступа организуйте защищённый доступ к домашней сети. Секреты в строке команды могут остаться в истории терминала; при возможности задавайте их через интерфейс.

DNS-перехват не охватывает произвольный DoH, а текущие маршруты — IPv6. Ограничения описаны в [архитектуре](docs/ARCHITECTURE.md). Автоматически полученный pin частного сертификата требует доверия первому соединению.

Не публикуйте реальные конфиги, VLESS/Hysteria-ссылки, токены, пароли, MAC, дампы роутера или резервные копии. Если секрет уже опубликован, удаление файла недостаточно: отзовите/замените секрет и проверьте историю Git.

Для сообщения об уязвимости используйте GitHub Security → Report a vulnerability, если приватные сообщения включены владельцем. Если кнопки нет, создайте issue только с просьбой предоставить приватный канал, без деталей эксплуатации и секретов. Технические ошибки без чувствительных данных можно сообщать обычным issue.
