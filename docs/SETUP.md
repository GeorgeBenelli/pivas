# Настройка

## Веб

```sh
pivas web on 'ЗАМЕНИТЕ_НА_СВОЙ_ПАРОЛЬ'
pivas web status
```

Адрес: `http://АДРЕС_РОУТЕРА:8888`, логин `admin`. Используйте свой пароль, отличный от пароля SSH. Пароль можно задать отдельно: `pivas web pass 'НОВЫЙ_ПАРОЛЬ'`.

Веб включается только по команде. `pivas web off` останавливает его и отключает автозапуск; настройки сохраняются. Эта команда не ставит на паузу сам Pivas.

## Слоты

Сохраните ссылку в карточке слота и при желании задайте понятное название. Поддерживаются VLESS TCP + Reality, gRPC + TLS, XHTTP + TLS/Reality и Hysteria 2. Параметры конкретной ссылки должны поддерживаться импортёром и сервером.

Настроить ссылку можно и в CLI:

```sh
pivas vless set-1 'ВСТАВЬТЕ_СВОЮ_ССЫЛКУ'
pivas vless set-2 'ВСТАВЬТЕ_СВОЮ_ССЫЛКУ'
```

Второй слот необязателен: при отсутствии отдельного подключения используется профиль первого. Веб различает такой режим и два отдельно настроенных слота.

«Поменять ссылки» меняет серверные подключения местами; группы и названия остаются в своих слотах. То же действие доступно в боте и через `pivas vless swap`.

## Группы и устройства

Создайте группу, выберите слот и добавьте домены по одному в строке. Можно добавлять IPv4 и CIDR. Запись `example.com` покрывает её поддомены; перечислять каждый поддомен не обязательно. Для отдельного маршрута поддомен можно задать более конкретным правилом.

Группу можно переименовать, приостановить, перенести в другой слот или удалить целиком. Повторяющиеся записи нормализуются; пересечения групп и правила разных слотов проверяются каталогом, поэтому лучше работать через интерфейс, а не вручную править файлы.

В разделе устройств выберите «Без Pivas», чтобы исключить устройство из маршрутизации и перехвата DNS Pivas. Лимит — 10 исключений, привязка по MAC. Wi-Fi, Ethernet и частный MAC могут представляться разными устройствами. Ранее открытым соединениям иногда требуется переподключение.

## Включение и проверка

```sh
pivas start
pivas status
pivas vless ping
```

`net` — доступность TCP сервера; `e2e` — запрос HTTPS через Xray. Hysteria 2 использует QUIC/UDP. Работающий процесс или успешный TCP-ping не доказывает прохождение клиентских маршрутов.

Пауза: `pivas stop`. После изменения правил обновите соединение с проверяемым сайтом; DNS-кэш браузера и устройства может сохранять старый адрес.

## Telegram

В вебе задайте токен от BotFather и разрешённые числовые ID администраторов. Можно использовать CLI:

```sh
pivas bot token 'ТОКЕН_ОТ_BOTFATHER'
pivas bot id 'ВАШ_ЧИСЛОВОЙ_ID'
pivas bot on
```

Бот предоставляет администратору управление роутером; не выдавайте доступ посторонним. При пустом списке администраторов управление запрещено. Настройте рабочие слоты до запуска: штатное подключение бота использует локальный прокси Xray.

## Резервная копия

В вебе создайте зашифрованную копию и храните её вне флешки роутера. В копию входят ссылки, группы, домены, исключения и DNS-настройки. Токен бота и пароль веба на новом устройстве задаются отдельно. Диагностический отчёт резервной копией не является.
