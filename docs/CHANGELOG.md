# История версий

## 1.2.0-beta.1 — 2026-10-10

- Проверка файлов DNS-служб при установке, повторной установке и `pivas start`.
- Восстановление отсутствующих `S56dnsmasq` и `S09dnscrypt-proxy2` из локальных шаблонов; пользовательские DNS-конфигурации сохраняются.
- Команда `pivas repair-dns`, состояние файлов служб в диагностике и понятная ошибка запуска в вебе.
- Старые процедуры остановки больше не переименовывают эти init-скрипты.

Версии компонентов указаны в `manifest.json` релиза.

## 2026-10-02 — Xray на MIPSel

- Xray 26.3.27 для MIPSel пересобран из исходников v26.3.27 с Go 1.26.6 и softfloat для совместимости с ядром Keenetic. AArch64 использует официальный бинарник.

## 2026-10-02 — XHTTP

- Xray 26.3.27 и VLESS XHTTP + TLS/Reality.
- Импорт и экспорт транспорта в CLI, вебе и боте; поддержка длинных ссылок через TXT.
- Миграция параметров Hysteria и старых резервных копий.

## Ранее

- Hysteria 2 внутри Xray, Salamander и проверка сертификатов через одноразовый QUIC-помощник.
- Общие имена слотов и обмен ссылками.
- Монохромный адаптивный веб, автоматическая тема, настройка бота через веб.
- Группы доменов, IPv4/CIDR, исключения устройств, диагностика и резервные копии.
