# Обновление

Перед обновлением скачайте зашифрованную резервную копию Pivas. Сохраните предыдущий установщик и доступ к SSH. Выбирайте ту же архитектуру Entware.

## Полный пакет

Текущая поставка использует `pivas-full`: он включает все компоненты и обновляется одним IPK своей архитектуры. Не применяйте `--force-overwrite` для обхода конфликтов. Если на роутере сохранилась старая установка отдельными пакетами, сначала нужна миграция на полный комплект.

## Через Telegram

Откройте «Сервис → Обновить пакет» и отправьте IPK **как документ**, не как текст и не как `.sh` или `.tar.gz`. Полный пакет включает ядро Pivas, веб, бот, Xray и QUIC-помощник. Лимит файла бота — 20 МБ.

Если старый бот отвечает, что `pivas-full` не разрешён, обновление нужно выполнить через SSH; список разрешённых пакетов на старом боте не меняется от переименования файла. Обновления доступны только разрешённым администраторам.

## Через SSH

Передайте подходящий IPK в `/opt/tmp/` и выполните, подставив реальное имя файла:

```sh
opkg update
opkg install /opt/tmp/ИМЯ_ПАКЕТА.ipk
```

Скрипты установки оставляют Pivas на паузе. Проверьте `pivas status`, затем явно включите `pivas start`. При обновлении через бот помощник пытается вернуть прежнее состояние; итог всё равно проверьте. После замены бинарника Xray убедитесь, что процесс перезапущен; в согласованное время можно перезагрузить роутер и проверить автозапуск.

## После обновления

```sh
pivas repair-dns
pivas status
pivas vless ping
```

Проверьте сайт из каждого настроенного слота, обычный сайт вне списков и устройство с исключением. Тест слотов с роутера не заменяет проверку с клиента. Обновление сохраняет пользовательские конфигурации; токены и серверные ссылки в дистрибутив не включены.
