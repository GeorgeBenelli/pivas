# Диагностика

## Сайты не открываются

```sh
pivas status
pivas vless ping
pivas dns watchdog status
pivas diag > /opt/tmp/pivas-diag.txt
```

Отчёт можно скачать в вебе или получить через «Сервис → Диагностика» бота. Укажите конкретный домен, слот, модель, версию KeeneticOS и результат с клиентского устройства. Перед передачей отчёта просмотрите его: секреты маскируются, но домены, IP, MAC и имена устройств остаются.

Проверьте, включены ли Pivas и группа, не находится ли устройство в исключениях. Затем сравните e2e слота с DNS-проверками в отчёте. При успешном слоте и неработающем клиенте проверяются Proxy client, перехват DNS, Netfilter, IPv6, DNS-кэш и собственный VPN/DoH клиента. Не объявляйте ссылку неисправной только по одной неудачной проверке с другой сети.

## Нет S56dnsmasq или S09dnscrypt-proxy2

```sh
pivas repair-dns
```

Custom31 восстанавливает отсутствующий скрипт из локального шаблона и проверяет зависимости. Он не перезаписывает настройки DNS и не скачивает пакеты самостоятельно. Если отсутствует бинарник, следуйте сообщению проверки, например:

```sh
opkg update
opkg install --force-reinstall dnsmasq-full dnscrypt-proxy2
pivas repair-dns
```

Эти команды предназначены для установки Pivas с указанными зависимостями, а не для произвольного роутера с другим DNS-сервисом. Сообщение `resolve_conffiles ... -opkg` обычно означает сохранение существующей конфигурации и запись новой рядом; это не равнозначно отказу установки. Смотрите итоговый код и проверку служб.

## Веб и бот исчезли после выключения питания

Сначала проверьте, видит ли Keenetic USB-накопитель и выбран ли он в OPKG. Если Entware-флешка не подключена, Pivas запустить неоткуда, хотя админка Keenetic продолжает работать. Не форматируйте накопитель до проверки подключения и журнала. На новой пустой флешке Entware и Pivas устанавливаются заново, настройки восстанавливаются из копии.

## Ссылка XHTTP отклонена

Импортёр поддерживает не все расширенные поля. В custom31 поле `mode` внутри JSON `extra` отвергается, даже если такая дублированная запись допустима Xray. Если `mode` уже задан отдельным параметром URL, удалите только его дубль из `extra`; остальные параметры сохраняйте. Это известное ограничение импортёра, а не доказательство неработоспособности сервера.

## Что не отправлять в публичный issue

Не прикладывайте рабочие VLESS/Hysteria-ссылки, токены, пароли, конфиги Xray, резервные копии, SSH-ключи и полный конфиг Keenetic. Для примера ссылки замените учётные данные и адрес сервера на вымышленные значения, сохранив названия параметров.
